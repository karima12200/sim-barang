# SIM-Barang

## Deskripsi Proyek

SIM-Barang adalah sistem pengelolaan inventaris barang jurusan yang digunakan untuk membantu pencatatan dan pemantauan barang di laboratorium maupun lingkungan jurusan.

## Konsep HTTP Request dan HTTP Response

### HTTP Request

HTTP Request adalah permintaan yang dikirimkan oleh client, seperti browser, kepada server untuk meminta atau mengirimkan data.

### HTTP Response

HTTP Response adalah tanggapan yang diberikan oleh server setelah menerima dan memproses permintaan dari client.

## Tujuan Proyek

Membangun aplikasi web inventaris barang secara bertahap menggunakan HTML, CSS, JavaScript, PHP, dan MySQL.
